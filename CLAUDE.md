# Privacy Policy

**Never write sensitive, personal, identifying, or private data to this repo.**

This includes but is not limited to:

- API keys, tokens, secrets, passwords, or credentials
- Real names, emails, user IDs, or payroll IDs
- Company names, internal URLs, or org structure data
- Personal health, financial, or HR data
- Any data sourced from a real Motivosity (or other) instance

Skills should use placeholder values in examples (e.g. `user@company.com`, `<API_TOKEN>`, `<userId>`).
